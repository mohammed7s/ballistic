Raw, but organized.

Keep the existing app’s plain labels, visible status and technical detail. Use a consistent type scale, aligned values and separators to make it readable.

What changed

Top tabs return; Settings moves to a gear. No marketing headline, decorative cards, fake hardware gauges or oversized empty areas. Monospace is reserved for measurements and raw records.

Review the controls

All four screens include the existing feature groups. Buttons marked by the demo notice simulate behavior; no settings, credentials or models are sent anywhere.

The feature decisions below are proposals for us to review—not instructions to delete functionality.

Feature decisions for this pass

AreaKeep / reorganizeDecision
AskDirect prompt; model name and local/connected disclosure; authentication; phase, elapsed timer and Stop; honest result/evidence/error; demo-engine warning when applicable.Keep run status above the pinned bottom prompt. Session controls move to Settings.
Request detailEvery action, reason and outcome. Result evidence and failure detail. Timing and execution state where recorded.Live summary; expand full trace. Recent requests remain at the bottom.
ActivityAll recorded history, sensitive-content toggle, refresh, timestamps, step duration, task/execution status, errors, engine identity and available token counts.Keep all. Propose request grouping and 7-day filter; no automatic deletion.
Local AICurrent model; model routing moves to Settings; authenticate when needed; verified starter download, progress, cancel and errors; GGUF import/copy/dismiss; load/unload/remove; free storage.Keep controls. Separate model setup from measurements.
MeasurementsSpeed check, input/output tokens, generation/prefill rate, first token, load/call time, generation cap and memory.Main values visible; timing breakdown in details. After-call values are not live rates.

SecuritySession controls in Settings; authenticate on request/setup when needed; auto-lock; separate exact-action approval with app, verb, target, values/source and reason.Preserve behavior. Authentication does not grant phone-control permissions.

Try it on the emulator

Type instructions, watch an AI operate an Android phone, and read the benchmark results.

The setup

  • The phone is an Android emulator (Android 13, the version AndroidWorld targets) running with a window on the ThinkPad's desktop. It is a test phone with fake contacts, messages and files, and none of your accounts.
  • The agent today is AndroidWorld's stock agent; Ballistic's own agent replaces it in step 2 (The agent).
  • The model is Google's Gemini gemini-flash-lite-latest on the free tier, reached over its OpenAI-compatible interface. The key is in ~/.ballistic_env on the ThinkPad and never in the repo.

Type instructions one at a time

On the ThinkPad (or over SSH to it):

cd ~/Dropbox/WEB/brainandbot/ballistic
bash harness/chat.sh

Then type at the prompt and watch the emulator window:

ballistic> open the Clock app
  ...the steps scroll by...
done: 2 steps, 12.4s
ballistic> add an alarm for 7:15
ballistic> turn on wifi
ballistic> /quit
At the promptDoes
any textan instruction for the agent
/homego to the home screen
/steps 25allow more steps per instruction (default 15)
/quit or Ctrl+Dleave
Ctrl+C while it worksstop that instruction, back to the prompt
↑ / ↓earlier instructions
Good to know
  • Each instruction starts from whatever screen is showing, so you can build on the last one ("open Contacts", then "add Sara, 555 1234").
  • The agent does not remember earlier instructions; "now change it to 8" will not work. Say what "it" is.
  • Do not touch the emulator window while it is working; between instructions you can.
  • It reads the screen's structure, not pictures. Sliders, dragging and apps that show a blank structure are hard for it.
  • "Could not get a11y tree, retrying" means the screen description was not ready yet; it usually recovers.
  • Every instruction is saved as ~/ballistic_runs/<time>_Chat.json.

Run a benchmark task

A benchmark task sets the phone up, gives the agent the instruction, and checks the result automatically:

cd ~/Dropbox/WEB/brainandbot/ballistic && source ~/.ballistic_env
~/android_world/.venv/bin/python harness/run_task.py --task SimpleSmsSend \
  --model gemini-flash-lite-latest \
  --base_url https://generativelanguage.googleapis.com/v1beta/openai/ \
  --api_key "$BALLISTIC_API_KEY" --max_tokens 2000 --timeout 120

It ends with PASS or FAIL. --list shows all 116 task names.

Run the 20-task suite

bash harness/run_suite.sh          # one task after another; prints a pass table

Results go to ~/ballistic_runs/suite_<time>.tsv, with one JSON file per task next to it: every step, the model's reasoning, prompt sizes and timings. Only one thing may use the emulator at a time: do not run chat.sh while a suite is running.

When something goes wrong

You seeMeaning
429 or "quota" in the outputThe free Gemini allowance for the day is used up.
Error calling LLMThe model could not be reached (network); the step is retried a few times.
Emulator window goneRestart it on the ThinkPad: WINDOW=1 bash harness/run_emulator.sh start
The agent keeps waiting on a blank screenThe app gave an empty screen description; Ctrl+C, /home, try again.
